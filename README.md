# Programación II

**Autor:** Martin Caza
**Institución:** Universidad Tecnológica Equinoccial (UTE)

Repositorio con las prácticas y proyectos de la materia.

## Contenido

| Carpeta | Descripción |
|---|---|
| `practicas_python/` | 17 prácticas de Python: variables, ciclos, funciones, excepciones y POO (clases, herencia, polimorfismo, clases abstractas). |
| `django1/` | Proyecto introductorio de Django: sistema de reservas (modelos, relaciones, formularios, vistas, ORM). |
| `django2/restaurante-app/` | Proyecto de Django: menú de restaurante con CRUD, autenticación, grupos y permisos. |

## Entorno
- Python 3.x y Django 6.1.
- SQLite por defecto; PostgreSQL opcional en `django2` mediante `.env`.
- Cada proyecto tiene su propio `requirements.txt` y README con las instrucciones.

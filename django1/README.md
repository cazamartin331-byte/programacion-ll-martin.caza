# Django 1 — Sistema de reservas

Autor: Martin Caza — Programación II, UTE.

Proyecto introductorio de Django: modelos, relaciones uno a muchos, formularios,
vistas de función, plantillas y el ORM.

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser   # opcional, para /admin/
python manage.py runserver
python manage.py test
```

Los ejercicios del ORM están en `orm_ejercicios.md`.

Los datos de ejemplo se cargan con `python manage.py cargar_datos`.
La lista de ejemplos para las evidencias está en `ejemplos.md`.
